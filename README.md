CLOUD CAMPUS – Event and Programme Management System


CLOUD CAMPUS is a web-based Event and Programme Management System developed to simplify and digitalize the management of campus events and student participation. The platform provides an organized, efficient, and user-friendly environment for administrators, event managers, and students to manage all event-related activities in a centralized system.

The system allows event managers to create events and programmes, students to participate in various activities, and administrators to monitor and control the entire platform effectively.

✨ Features
👨‍💼 Admin Module
Secure admin login
Manage students and event managers
View all events and programmes
Monitor participation records
Manage system activities
Maintain platform security and coordination
🎤 Event Manager Module
Event manager registration and login
Create and manage events
Add programmes under events
Set programme rules:
Minimum and maximum participants
Allowed song/content type
Time limits
Approve or reject participation requests
Manage event details and schedules
👨‍🎓 Student Module
Student registration and login
View available events and programmes
Join programmes and activities
Submit programme details:
Team name
Song name
Number of participants
Track participation status
Receive notifications and updates
Create chat groups and add members
🎯 Objectives
Digitalize campus event management
Simplify programme registration and participation
Improve coordination between students and event managers
Reduce manual errors and data loss
Provide a centralized platform for all event activities
